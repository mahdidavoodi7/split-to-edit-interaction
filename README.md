# ⏱️ Split to Edit Interaction

A smooth, animated time editor built with:

- [Expo](https://expo.dev)
- [react-native-reanimated](https://docs.swmansion.com/react-native-reanimated)

This project showcases a split to edit UI where the time fields expand, round out, and become editable through a clean animated transition — all powered on the UI thread for a snappy native feel.

## 🚀 Features

• Smooth width expansion for hours and minutes  
• Animated rounded corners and spacing changes  
• Edit mode toggle with spring animations  
• Fully UI thread powered with Reanimated  
• Clean iOS-inspired time input interaction  
• Works on both iOS and Android

## 🛠️ Usage

```sh
git clone https://github.com/mahdidavoodi7/split-to-edit-interaction
cd split-to-edit-interaction
npm install
npx expo run:ios

Or for Android:

npx expo run:android
```
